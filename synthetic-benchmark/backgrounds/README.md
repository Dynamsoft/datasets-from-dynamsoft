# Background textures

The original `atlas.png` was generated with the built-in ImageGen tool. The twelve PNG
tiles in `tiles/` are the crops used for compositing, in row-major order. Four pixels
are removed from each tile edge to avoid including an adjacent texture. Keep the atlas
as the canonical generator input and the individual tiles for reuse.

The scene references came from the themes in this repository's `challenging-images`
collection, including crumpled paper, receipts, luggage, shiny packaging, and shadows.
The generation prompt used text descriptions of these themes. The corpus uses only
the newly generated texture crops and programmatically rendered symbols.

The grouped review also uses `scenes-atlas-1.png` and `scenes-atlas-2.png`, generated
with the built-in ImageGen tool. These add 24 packaging and workplace scenes for
36 total. The generator uses a different crop, orientation and lighting gradient per
image. All individually cropped textures are in `tiles/`.

## Generation prompt

> Use case: photorealistic-natural. Make one production texture atlas, exactly 4 columns and 3 rows, twelve equal-size rectangular full-bleed tiles in a landscape 4:3 overall composition, straight tile boundaries, no gutters or frames. Each cell is an independent close-up photographic background for compositing synthetic barcode labels. Top row left to right: warm brown kraft corrugated carton with diagonal box edge; crumpled off-white thermal receipt paper with subtle gray shadows; light gray brushed metal with a broad specular highlight; dark navy charcoal woven luggage fabric curved across frame. Middle row: matte pastel blue medical-grade plain plastic wrap with creases; off-white pearl coated glossy package with an oblique broad light reflection; deep maroon cardboard with lightly rubbed texture; weathered warm pale gray concrete/warehouse floor. Bottom row: pale cool gray paper overlapped by a second blank sheet and a corner shadow; strongly side-lit honey kraft carton with clear glossy packing tape; olive green dark canvas with large soft shadow; lavender gray transparent polyethylene film with folds on neutral gray. Stay at human-scale close crops, believable color and microtexture, lighting from a range of angles. These are blank material surfaces, no text, symbols, graphics, dots in grids, printed markings, logos, QR codes, labels with content, stripes that resemble a barcode, watermarks, or objects beyond the described material. No typography. Each tile should remain usable edge-to-edge as a texture. The tile arrangement is important.
